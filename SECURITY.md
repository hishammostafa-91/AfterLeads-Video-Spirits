# Security Policy

## Supported versions

Security fixes are provided for the latest released minor version of AfterLeads-Video-Spirits. Before 1.0 there are no supported releases.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

- Preferred: GitHub private vulnerability reporting at https://github.com/hishammostafa-91/AfterLeads-Video-Spirits/security/advisories/new
- Or email: afterleadseg@gmail.com with the subject "Security: <short summary>"

Include the affected version, a description, reproduction steps or a proof of concept, and the impact you expect.

## What happens next

1. Acknowledgement within 7 days.
2. Assessment and a fix timeline: critical issues within 7 days, high within 14 days of confirmation (docs/05-security.md SEC-12).
3. A patched release and a GitHub Security Advisory; reporters are credited if they wish.

## Scope

In scope: the application, its installer and updater, file parsers (projects, media handling, captions, LUTs), the IPC boundary, and the release pipeline. Out of scope: vulnerabilities in third-party software that the project does not ship, and social engineering.

The application collects no telemetry. Please do not include personal data that is not needed for the report.
